# Proposed V4 work — not implemented or scored in this frozen audit

1. **Gate requirement event tags by initial applicability.** A controlled initially
   unsupported object later placed on the table keeps a not-applicable run verdict,
   but V3 labels its later physical fall `r1_fall/in_scope`. Keep physical motion and
   requirement event status separate. Add an invariant that no definitive R1 event
   lacks established initial applicability. The 300 new empirical outputs contain
   no such contradiction; the counterexample is explicitly synthetic.
2. **Compose qualified observation evidence across state transitions.** All 100
   task-01 predicted-applicable cases abstain despite complete recordings, while
   V3 classifies 100 lifts and 87 post-lift drops. Assess whether table support,
   established holding and approved outside-R1 phases can compose a qualified
   claim domain. Retain abstention for unresolved re-placement semantics; obtain
   scope-owner clarification before changing those meanings. Do not simply turn
   all post-lift intervals into negatives to improve coverage.
3. **Validate scene-specific input bindings rather than reuse numeric IDs.** Different
   XML/body/native counts fail closed in 38 other task preflights. Build audited,
   per-recording mappings covering all owned table collision geometry (including
   currently omitted ID 15), object bodies and robot roles. Keep the named R1 scope
   intact; do not rename different surfaces or substitute protected objects silently.
4. **Study support under measurement noise and supported motion.** A 1e-10-m
   represented pose change triggers the exact-rest rule's abstention. Any physical
   stability tolerance needs independent measurement justification/calibration, not
   tuning on this cohort. Contacts alone do not measure load bearing. Consider
   recording contact normals/forces with validated phase provenance in future data.
5. **Validate the boundary contract.** All eligible inputs here genuinely have ten
   settling commands/frame-10 boundary. Keep rejecting incompatible timelines rather
   than silently moving the requirement boundary for another recorder.
6. **Obtain independent reference labels and genuine in-scope positives.** Finish the
   two-reviewer blinded handoff and adjudication. If positives remain absent, use a
   separately declared independently reviewed positive corpus without weakening R1.
   Include conditional and end-to-end recall with abstentions counted as missed
   positives when appropriate. Never turn the 87 predicted post-lift drops into R1
   positives or synthetic fixtures into empirical detector-validation examples.

Any implemented V4 must have its own source/config freeze, predictions and prospective
run/task/seed separation. No after-the-fact tuning of V3 is included in these results.
