# Semantic retrieval assessment

Structured metadata and FTS are sufficient for the evaluated source-selector and keyword queries. This is not a claim of general natural-language coverage. A separately recorded five-case paraphrase probe asks where an object is, which bodies touch, robot movement, observation time and linked images. Expected relevance is a specific existing source window, not a physical event. Keyword and metadata versions retrieve each target. Literal conjunction can miss ordinary paraphrases; see SEMANTIC_PROBE.json for observed results.

Natural-language evidence discovery could benefit from semantic retrieval. This remains a hypothesis until tested against diverse, independently specified source-relevance queries. No encoder, vector database, external API or model download was added. Existing metadata/FTS retrieval remains fully functional.

Proposed optional semantic index version: `semantic-source-index:1.0.0`, separate from the immutable evidence database. Before construction, pin an approved local text encoder repository, immutable revision, weight/tokenizer hashes, dimensions, dtype and normalization, plus a license/resource check. No model identity/revision is guessed here. Deterministic input text should contain only source-attributed descriptions, task instructions and explicit uncertainty, with a text digest tied to each evidence ID. Raw numeric frames/media and unverified physical labels are not embedding targets.

Store `(evidence_id, record_digest, text_digest, model_binding_digest, vector)` in a separate /disk/1 artifact with a versioned build manifest. Apply exact execution/task/object/requirement/stratum/interval/capability filters before nearest-neighbor ranking; validate source/dependency integrity again afterward. Stable ID breaks score ties. Shared source copies are not independent evidence. Embeddings must never change measurement validity, uncertainty, coverage or safety status.

Evaluate structured-only, FTS-only and optional hybrid retrieval using a prospectively frozen source-relevance set with paraphrases, counterevidence and missing-source cases. Report Recall@k, Precision@k, MRR and latency with identical metadata filters. Keep this separate from physical ground truth and held-out safety labels. Implement the optional index only after model/protocol selection; no comparative embedding results are claimed in Phase 5C.
