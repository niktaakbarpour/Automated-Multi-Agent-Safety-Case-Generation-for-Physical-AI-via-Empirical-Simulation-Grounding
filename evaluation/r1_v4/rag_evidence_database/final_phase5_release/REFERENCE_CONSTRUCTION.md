# Independent reference construction

reference.py constructs request/reference pairs without importing the target API, planner or completeness checker. It uses direct h5py reads, original HDF5 attributes, source JSON, verified XML/native model maps and preserved geometry/alias contracts. Expected statuses are predetermined from those contracts. Raw arrays, dtype/shape/selector, component order, declared scope, metadata fields and complete source-selector sets are checked independently; retrieved outputs are never copied into labels.

Selection is deterministic and stratified across four task suites, four fresh execution scopes per suite. scopes() starts from the indexed eligible corpus; excluded_scopes plus earlier K.1 development/final selections remove previously exposed question scopes. Reserved/preflight payloads are not accessed. FINAL_SELECTION.json records exact eligible selections, source hashes and bindings. The 28 request types are structured schema operations, not novel linguistic paraphrases.

FROZEN_IMPLEMENTATION_CONFIGURATION.json precedes dataset construction; FROZEN_RELEASE_CONFIGURATION.json binds the implementation, dataset and selection plus all zero-error acceptance criteria before final retrieval. No final cases, labels, exclusions or acceptance criteria changed after evaluation. The later independent_set_audit strengthens set/cardinality checking against the same frozen references without changing labels. Source contracts are shared primary premises, so independence does not imply freedom from every correlated upstream error. No human annotation or physical-safety judgment is claimed.
