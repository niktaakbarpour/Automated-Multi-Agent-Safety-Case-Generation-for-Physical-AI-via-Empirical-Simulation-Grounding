# Uncertainty register

A null physical bound means unknown, never zero. Observation extrema describe this development sample; they are not automatically conservative bounds for another run or the underlying physical process.

| ID | Component | Established information | Unresolved limitation / consequence |

## Propagation obligations

Retain execution/object/piece identities, transforms, source hashes, source clocks, validity intervals and dependencies. Shared cameras/exports of the same recording are not independent evidence. Intervals can conservatively propagate arithmetic even with dependence; they cannot repair missing physical input bounds. Never combine endpoint shape with earlier contacts without a valid phase contract.

Every physical support/fall/clear claim must carry all necessary uncertainty and admission dependencies. Unknown support, scope, phase or geometry prevents a definite claim. Contradictory admissible evidence suspends affected witnesses; majority/AI agreement does not resolve it. Existing V4 logic already preserves these distinctions and is unchanged here.

Only P01/P02 provide justified numerical methods, explicitly marked computational. P03–P10 remain BLOCKED_ON_EVIDENCE. No distance, contact, persistence, hysteresis or alignment default is introduced. No sample quantile/extremum is promoted to a physical confidence bound.
