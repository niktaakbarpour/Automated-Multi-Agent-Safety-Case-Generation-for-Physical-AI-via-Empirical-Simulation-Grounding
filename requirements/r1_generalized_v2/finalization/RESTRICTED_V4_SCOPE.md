# Restricted V4 scope

## Approved design, available for a subsequent implementation task

- Configuration 2.0.1, embedded manifest 1.0.0, semantic identity/mapping/boundary
  checks and typed assessment/diagnostic records.
- Arbitrary explicit protected sets, multiple verified static roots and per-object
  unions; stable IDs, no implicit alias repair or LLM scope selection.
- Dependency-scoped validity and conflict admission; full per-object vector and pure
  deterministic execution aggregation over already admitted outcome records.
- Analytical conformance fixtures with explicit exact assumptions. Fixture and legacy
  comparison purposes remain separate from empirical assessment.
- First adapter target: bound LIBERO recorded-state evidence, rigid BOX geometry,
  verified static horizontal support roots, direct or admitted finite acyclic
  single-parent support. Saved-frame projection with explicit transition cells;
  conditional cameras and handling evidence. This is an intended capability boundary,
  not evidence that any empirical profile is currently validated.

## Deferred / excluded from initial release

Moving/articulated support, multiple-parent load inference, complex handoffs,
automatic re-arm, dynamic reassignment, general dynamic/handling negative composition,
vision-only inference, non-BOX empirical geometry, deformables and other benchmarks.
No runtime fallback to BOX, default table IDs or contact-as-support inference.
Unsupported necessary capability yields IC; transient missing/ambiguous evidence
under a supported contract yields U. Abstract static union meaning does not implement
handoff inference. New task/scene bindings require scope-specific admission.

## Empirically blocked

Calibration, recorder/state/contact phase, geometry/gravity/pose uncertainties,
absence completeness, staticness/load-bearing/handling inference, real negative
certificates and independent reference evaluation. No definite physical outcome is
licensed until its necessary evidence contracts pass the gates. No continuous-time
safety, LIBERO-wide capability or certification claim is made.
