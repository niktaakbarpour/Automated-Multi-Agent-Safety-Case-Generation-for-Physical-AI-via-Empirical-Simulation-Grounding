\subsection{Frozen-checker transfer and overfitting audit}
We evaluated the unchanged R1 v3 checker on ten reserved executions of the original task and fifty executions of a second task in the same scene. The second task manipulates cream cheese and butter, which were protected distractors in the development task. All 60 recordings passed identity and checksum checks; inference produced 300 sealed object--execution predictions from 15,515 snapshots without extraction errors. No duplicate complete trajectories were found among these executions and the original four. Prior numerical/setup inspection and global inventory exposure prevent calling these sets pristine held-out data.

The checker predicted 20 applicable units in the reserved same-task set and issued 20 coverage-qualified negative outputs. In the changed-task set it predicted 100 applicable units but abstained on all 100, despite complete measurements. This exposes a task-dependent decision-coverage limitation of its full-domain static-support proof. These numbers describe predictions, not independently verified accuracy: no human reference exists yet for the new executions. Applicability confusion, false-alarm rates, R1 recall and event-localization accuracy therefore remain pending. An independently generated evidence-only package provides full videos, neutral measurements and blank forms for two reviewers. The frozen mapping rejected 38 other task preflights, so empirical cross-scene performance is not established.
