# Proposed development parameters — unapproved

These values select geometric/kinematic **candidates**, not validated physical event labels or safety limits. Unresolved support-force direction, indirect support, contact/exposure phase, and interval endpoint coverage remain insufficient information. No parameter converts unknown evidence into a pass. No physical threshold uses the 6.50 mm raw-versus-simulator difference.

| Parameter | Base; sensitivity range | Rationale and limitation |
|---|---|---|
| Contact upper-face band | 0.1 mm; 0.01–1 mm | Same-bundle recorded contact location must be at an actual collision-box upper face and within its footprint. Object collision bottom must agree within twice this band; penetration must not exceed twice the band. Protected/table transform serialization bound is below 0.000061 mm; base is deliberately much larger than that numerical error, but much smaller than the thinnest protected-object extent (~18 mm) and tabletop thickness (~24 mm). This is a proposed candidate filter, not proof of load bearing. Deep penetration, side contacts and ambiguous support remain unresolved. Model margins/solref/solimp are saved with the actual XML; they do not establish a physical support tolerance. |
| Descent per observed interval | 0.1 mm; 0.01–1 mm | Bounding-box center (not root/COM/table height) must descend across two successive contact-free intervals. This rejects numerical jitter, while retaining subtle candidate motions. Shape rotation can change the AABB center; candidate evidence must be reviewed with rotations and clips. This is not a minimum fall distance. Smaller/faster/inter-sample events can be missed. |
| Lift clearance | 1 mm; 0.5–2 mm | Collision bottom above the true upper table faces plus bilateral finger contacts indicates a possible mechanically supported lift. Contact without recorded forces cannot prove a grasp. This separates the post-lift branch conservatively; it is not an assertion of intention. |
| Persistence | Two intervals (0.10 s nominal) | Requires consecutive sampled descent evidence; limits false signals but misses shorter catches/falls. No continuous-safety claim. Review this choice before detector validation. |
| Timing arithmetic allowance | 1e-8 s | For float accumulation around 0.05 s control intervals only. Does not absorb missing samples or field phase differences. |
| Geometry composition guard | 512 float64 eps, coordinate-scaled position allowance | Copied v2 API; arithmetic consistency only. Rotation serialization is retained in corrected mapping. Not a physical tolerance. |

These are defensible exploratory ranges based on dimensions and numerical resolution, not calibrated event thresholds. The output sensitivity report compares all three profiles on the same development records. A stable result across profiles is not validation. Values requiring human scope decisions remain visible in config.json. Direct/indirect support and carrying interpretations require independently labelled evidence; no validated precision/recall is available.
